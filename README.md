# WPF-Exam-Project

This repository contains a WPF application built as part of an exam assignment. The project includes two main exercises (Vraag1 and Vraag2), each focusing on a different programming concept in C# and WPF.

##  Technologies Used

- C#
- WPF (Windows Presentation Foundation)
- .NET
- XAML

##  Project Structure

- `Vraag1.xaml` / `Vraag1.xaml.cs`: Implements a word frequency analyzer from user input.
- `Vraag2.xaml` / `Vraag2.xaml.cs`: Generates random numbers and converts them into Dutch text (e.g., 123 → "een twee drie").

##  Features

### Vraag 1 - Word Frequency Counter

- Users can enter a block of text.
- The application processes the input to:
  - Remove punctuation.
  - Split it into words.
  - Count the frequency of each unique word.
- The word and its count are displayed in a list format.

### Vraag 2 - Number to Dutch Text Generator

- When the "Generate" button is clicked:
  - Generates 10 random integers between 500 and 1500.
  - Converts each digit of each number into its Dutch word equivalent.
  - Displays the original number and its verbal representation in a list.
